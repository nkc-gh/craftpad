# To-Do List

To-Do List is a beginner-friendly web application for organizing, tracking, and managing daily tasks.

It features a personalized welcome screen, persistent task storage using browser local storage, and options to sort tasks by time, date, or creation order.

## Features

- Personalized welcome screen with saved username
- Add new tasks with specific dates and times
- Mark tasks as pending or completed
- Separate sections for pending and completed tasks
- Sort tasks by time, date, or created order
- Persistent storage using browser `localStorage`
- Edit and delete task capabilities
- Responsive and modern user interface

## File structure

```text
To-Do List/
├── to_do_list.html   # Main HTML webpage
├── style.css         # CSS styles and layout
├── script.js         # Application logic and localStorage handling
└── README.md         # Project documentation
```

## How to run

### 1. Open directly in a web browser

Double-click `to_do_list.html` or right-click and select **Open With** followed by your browser (e.g., Chrome, Firefox, Edge).

### 2. Run using VS Code Live Server (Optional)

If you use Visual Studio Code:
1. Install the **Live Server** extension.
2. Right-click `to_do_list.html`.
3. Select **Open with Live Server**.

Enter your name on the welcome screen to get started, then begin adding and managing your tasks.
