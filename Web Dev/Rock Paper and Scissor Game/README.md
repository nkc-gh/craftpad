# Rock Paper and Scissor Game

Rock Paper and Scissor Game is a beginner-friendly web game where a player competes against the computer.

It provides an interactive visual interface to make choices, calculates game outcomes in real-time, and tracks live scores.

## Features

- Interactive graphical choices (Rock, Paper, Scissors)
- Computer choice generator with equal probability
- Real-time round outcome display (Win, Lose, Draw)
- Live score tracking for both player and computer
- Dynamic score updates without refreshing the page
- Responsive and clean UI styling

## How to run

### 1. Open directly in a web browser

Double-click `rock_paper_scissor.html` or right-click and select **Open With** followed by your browser (e.g., Chrome, Firefox, Edge).

### 2. Run using VS Code Live Server (Optional)

If you use Visual Studio Code:
1. Install the **Live Server** extension.
2. Right-click `rock_paper_scissor.html`.
3. Select **Open with Live Server**.

Click on any choice (Rock, Paper, or Scissors) to start playing and watch your score update live.
